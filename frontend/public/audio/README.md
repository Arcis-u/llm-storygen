# Original synthesized ambience

These five WAV loops were generated for Nexus Tale using additive sine synthesis, without sampled or downloaded recordings. Each is 8 seconds, mono, 16-bit PCM at 16 kHz with a smooth sine-squared envelope.

Base frequencies (Hz): ambient 110/164.875/220; tense 110/116.5/165; combat 82.375/110/164.875; sad 110/130.875/164.875; epic 130.875/164.875/196. A quiet second harmonic adds texture. Playback and cross-fading are managed by src/lib/audio.ts.
